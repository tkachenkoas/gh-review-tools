# Privacy Policy

Last updated: 2026-09-16

GitHub Diff Defaults does not collect, sell, or transmit personal data.

The extension stores review preferences in Chrome Sync. It reads the current
GitHub URL locally to identify a pull request's Changes page and apply the
selected filters. When automatic marking is enabled, it inspects loaded
diffs in the browser and uses GitHub's Viewed control for matching files.
The extension does not store URLs or diffs or send them to a separate service.
It does not use analytics, cookies, or third-party services.

For questions about this policy, open an issue in this repository.
